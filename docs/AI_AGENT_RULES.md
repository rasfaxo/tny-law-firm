# AI Agent Rules

AI agent wajib mengikuti rancangan skripsi.

Larangan:
- Jangan membuat tabel laporan.
- Jangan memakai ENUM di database.
- Jangan menambah fitur email.
- Jangan menambah payment.
- Jangan menambah integrasi e-Court.
- Jangan mengubah struktur database tanpa izin.
- Jangan menimpa dokumen lama saat unggah ulang.
- Jangan membuat Queue Worker untuk fase awal.

Aturan:
- Gunakan Laravel best practice.
- Gunakan migration, model, controller, request validation, middleware, policy jika diperlukan, dan service class untuk logika penting.
- Bangun fitur bertahap.
- Jelaskan file yang dibuat atau diubah sebelum coding.
- Setelah fitur selesai, tulis cara testing manual.
